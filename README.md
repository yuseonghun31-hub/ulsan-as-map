# 울산 AS 지도 (PWA)

울산 AS 방문 일정·동선 지도를 폰 홈 화면에서 주소창·안내 배너 없이 여는 웹앱입니다.
정적 파일(GitHub Pages)은 화면만 담고 있고, 자료는 구글 시트에서 PIN 잠금 API로 받아옵니다.

- 주소: https://yuseonghun31-hub.github.io/ulsan-as-map/
- 첫 실행 때 PIN을 입력하면 그 기기(브라우저)에만 저장되어 다음부터는 바로 열립니다.
- 헤더 오른쪽 `잠금` 을 누르면 저장된 PIN이 지워지고 다시 PIN을 묻습니다.
- 헤더 세 번째 줄이 **예약 날짜 칩**입니다(`전체` + `11/19(목)` 같은 날짜들 + `예약 없는 날`).
  날짜를 누르면 그 날 건만 지도 핀·아래 목록에 남고 지도가 그 핀들에 맞춰지며, 같은 칩을 다시 누르면 `전체`로 풀립니다.
  `경로 추천` 을 켜면 가장 가까운 예약일이 자동으로 잡히고, 이 날짜 칩으로 그날 동선을 바꿔 봅니다(패널 안에 따로 있던 날짜 줄은 없앴습니다).
- 아래 목록은 **구별로 묶지 않고 예약된 시간이 빠른 순서 한 줄**입니다: 예정 건(날짜 → 방문시간 오름차순, 같은 날은 시간 없는 건이 뒤) → `미확정` 건 → `완료 포함` 일 때 완료 건(최근 것부터). 구는 카드의 동 이름 태그 색(남구 초록·중구 노랑·북구 파랑·동구 분홍)으로 구분합니다.
  구 필터·예정만/완료 포함·날짜 칩을 걸어도 같은 시간순을 따르고, 고른 조건에 맞는 건이 없으면 목록 자리에 안내 한 줄이 뜹니다.
- 폰 세로 화면에서 지도와 아래 목록 사이 손잡이를 위아래로 끌면 지도·목록 높이 비율이 바뀝니다(지도 18~78%, 화면이 낮으면 지도 120px·목록 96px은 남깁니다).
  두 번 누르면 기본(지도 55%)으로, 손잡이 오른쪽 `목록 크게`로 목록을 넓게 볼 수 있고, 정한 비율은 그 기기에 저장됩니다.

## 지도

- 바탕은 **Esri Light/Dark Gray Canvas 타일**(공개 타일, 키 없음)입니다. 그 위에 경남 22개 시군구·부산·울주 경계를 옅게 깔고 **울산 4개 구를 도드라지게** 얹었으며, 방문 핀·이름·동선을 그립니다(어제의 그전 지도 방식 — 네이버 지도 JS API v3 는 걷어냈습니다).
- 핀의 **점 색은 예약된 요일별**입니다: 월 파랑 · 화 초록 · 수 청록 · 목 주황 · 금 보라 · 토 슬레이트 · 일 산호. **예약이 아직 없는(미확정) 건은 흰 점**, **완료 건은 회색 점**이고, 왼쪽 아래 범례에 같은 색으로 적어 둡니다.
- 열면 **울산 4개 구가 화면에 딱 들어오는 상태**로 시작합니다(첫 화면 = 울산 중심). 구 칩을 누르면 그 구만 확대합니다.
- 지도는 손가락·마우스로 자유롭게 이동·축소되고, 축소 한도는 **대한민국 전체**(위도 33.0~38.7, 경도 124.5~131.5 — 서울·강원·제주까지)입니다. 한 번 더 줄이면 대한민국 전체가 화면에 맞춰집니다.
- 밤/낮을 헤더 칩 `밤으로`·`낮으로`로 바꿉니다(그 기기에 저장, 저장한 적 없으면 기기 다크모드 설정을 따름). 밤에는 Esri Dark Gray Canvas 타일로 바뀝니다.
- 오른쪽 아래 `전체` 는 팀 구역(경남·부산)과 지금 보이는 핀까지 담아 맞추고, `울산` 은 울산 4개 구만 보여줍니다.
- 동선은 시트 `구간` 탭(네이버 길찾기로 받은 점들)을 지나는 부드러운 곡선(Catmull-Rom)으로 그리고, 지도 위에서도 읽히게 바탕색 테두리를 깔아 둡니다. 값을 아직 못 받은 구간은 점선(어림)입니다.
- 경로 추천을 켜면 집(양산)·사무실(부산 강서)까지 포함해 그날 동선 전체가 화면에 들어오게 맞춥니다.

## 고객 상세 카드 (열기 · 닫기)

- 목록 카드를 누르거나 지도의 **점(원)** 을 누르면 그 고객의 상세 카드가 목록 맨 위에 열리고, 지도는 그 위치로 확대됩니다.
- 카드 오른쪽 위 **`✕ 닫기`**(터치 영역 44px 이상)를 누르면 상세가 닫히고, 상세가 확대해 둔 지도 화면도 원래 보던 화면으로 돌아갑니다.
- 닫는 방법은 같습니다: `✕ 닫기` · 지도 빈 곳 누르기 · `Esc` 키 · 열었던 카드/핀을 다시 누르기.
  (상세를 연 뒤 지도를 직접 끌거나 확대·축소했다면 닫을 때 화면을 되돌리지 않고 그대로 둡니다.)

## 고객 이름 → 상세 카드 (전화는 카드 안에서)

- 목록 카드나 지도의 **이름표·점(원)** 을 누르면 전화가 걸리지 않고, 아래 정보란에 그 고객의 상세 카드가 **목록 맨 위**에 열립니다.
- 전화는 상세 카드 안의 **전화번호(`tel:` 링크)** 나 **`📞 전화 걸기`** 버튼을 눌렀을 때만 걸립니다(목록 카드에는 전화 링크가 없습니다).
- 거는 번호는 시트 `방문일정`·`구별 종합현황`의 `전화번호` 칸이고, 이 칸에는 모니터링이 **`증상접수 연락처`를 1순위**로,
  그것이 비어 있을 때만 `01 고객기본정보`의 연락처(대표번호)를 적습니다. `처리실적`의 완료 건은 그 표의 `연락처`를 씁니다.
- 번호가 비었거나 `-`·전산 더미값처럼 쓸 수 없으면 상세 카드에 전화 링크가 없습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 — Esri 회색 타일 위 경남·부산 경계 + 울산 4개 구 강조, 방문 핀(요일별 점 색·미예약 흰 점·완료 회색)·이름·동선·순서 번호·구/동 필터·**상단 예약 날짜 필터**·경로 추천·드래그 정렬·지도/목록 높이 조절 손잡이·상세 카드 `✕ 닫기`·네이버 지도 열기·접수번호 복사·카드 안에서 전화(tel:)·밤/낮 토글, PIN 잠금 |
| `manifest.json` | 앱 이름·아이콘·standalone(전체 화면) 설정 |
| `sw.js` | 화면·아이콘만 캐시(시트 자료·지도 타일은 캐시하지 않음) |
| `icon-*.png` | 앱 아이콘 |

이 저장소에는 고객 정보가 없습니다. 화면 코드와 행정동 중심 좌표만 있습니다.
화면 맞춤에 쓰는 행정동 좌표는 통계청 2013 시군구 경계(공개)를 지도 좌표로 옮긴 것이고, 배경 지도는 Esri Light/Dark Gray Canvas(© Esri, HERE, Garmin, © OpenStreetMap contributors)입니다.

## 자료 연결

`index.html` 의 `API` 상수가 가리키는 Apps Script 웹앱에 `?action=data&pin=…` 로 요청합니다.
PIN이 맞지 않으면 `{ok:false, unauthorized:true}` 가 오고 화면은 PIN 입력으로 돌아갑니다.
경로 추천 설정·순서 저장은 같은 주소로 POST(`{"action":"saveRoute","pin":…,"state":…}`)합니다.
