# 울산 AS 지도 (PWA)

울산 AS 방문 일정·동선 지도를 폰 홈 화면에서 주소창·안내 배너 없이 여는 웹앱입니다.
정적 파일(GitHub Pages)은 화면만 담고 있고, 자료는 구글 시트에서 PIN 잠금 API로 받아옵니다.

- 주소: https://yuseonghun31-hub.github.io/ulsan-as-map/
- 첫 실행 때 PIN을 입력하면 그 기기(브라우저)에만 저장되어 다음부터는 바로 열립니다.
- 상단은 **두 줄**만 둡니다: 1줄 **예약 날짜 칩**(`전체` + `11/24(화)` 같은 날짜들 + `예약 없는 날`), 2줄 **지역구 칩**(`전체`·`남구`·`중구`·`북구`·`동구`).
  날짜를 누르면 그 날 건만 지도 핀·목록에 남고 지도가 그 핀들에 맞춰지며, 같은 칩을 다시 누르면 `전체`로 풀립니다.
- 자주 쓰지 않는 기능(완료 포함 · 경로 추천 · 밤/낮 · 지금 새로고침 · 잠금)은 오른쪽 위 **`⚙` 메뉴** 안에 모았습니다. `잠금` 을 누르면 저장된 PIN이 지워지고 다시 PIN을 묻습니다.
  `경로 추천` 을 켜면 가장 가까운 예약일이 자동으로 잡히고, 날짜 칩으로 그날 동선을 바꿔 봅니다.
- **지도(위)와 아래 시트(정보·목록)를 한 화면에서** 봅니다. 시트는 늘 자리를 잡고 있고, 맨 위 **손잡이(약 56px)** 를 위아래로 끌면 손가락을 따라 높이가 부드럽게 바뀝니다.
  놓으면 **접힘(요약 한 줄) · 중간(지도+목록, 기본 42%) · 크게(목록 위주 78%)** 세 단계 중 가까운 곳에 붙고, 손잡이를 **한 번 톡** 누르면 다음 단계로 넘어갑니다(키보드 ↑↓·Home·End·Enter도 됩니다).
  목록을 맨 위에서 아래로 당겨도 시트가 따라 내려오고, 목록 본문은 시트 안에서만 스크롤되어 지도 조작과 엉키지 않습니다.
  시트가 화면을 거의 덮으면 범례 칩은 숨고 지도 출처 표기만, 지도 단추는 한 줄로 접힙니다.
- 목록은 **구별로 묶지 않고 예약된 시간이 빠른 순서 한 줄**입니다: 예정 건(날짜 → 방문시간 오름차순, 같은 날은 시간 없는 건이 뒤) → `미확정` 건 → `완료 포함` 일 때 완료 건(최근 것부터). 구는 카드의 동 이름 태그 색(남구 초록·중구 노랑·북구 파랑·동구 분홍)으로 구분합니다.
  구 필터·날짜 칩을 걸어도 같은 시간순을 따르고, 고른 조건에 맞는 건이 없으면 목록 자리에 안내 한 줄이 뜹니다.

## 지도

- 바탕은 **Esri Light/Dark Gray Canvas 타일**(공개 타일, 키 없음)입니다. 그 위에 경남 22개 시군구·부산·울주 경계를 옅게 깔고 **울산 4개 구를 도드라지게** 얹었으며, 방문 핀·이름·동선을 그립니다(어제의 그전 지도 방식 — 네이버 지도 JS API v3 는 걷어냈습니다).
- 핀의 **점 색은 예약된 요일별**입니다: 월 파랑 · 화 초록 · 수 청록 · 목 주황 · 금 보라 · 토 슬레이트 · 일 산호. **예약이 아직 없는(미확정) 건은 흰 점**, **완료 건은 회색 점**입니다. 왼쪽 아래 작은 `범례` 칩을 누르면 같은 색 안내가 펼쳐지고, 다시 누르거나 지도를 누르면 접힙니다.
- 열면 **울산 4개 구가 화면에 딱 들어오는 상태**로 시작합니다(첫 화면 = 울산 중심). 구 칩을 누르면 그 구만 확대합니다.
- 지도는 손가락·마우스로 자유롭게 이동·축소되고, 축소 한도는 **대한민국 전체**(위도 33.0~38.7, 경도 124.5~131.5 — 서울·강원·제주까지)입니다. 한 번 더 줄이면 대한민국 전체가 화면에 맞춰집니다.
- 밤/낮을 `⚙` 메뉴의 `밤으로 보기`·`낮으로 보기`로 바꿉니다(그 기기에 저장, 저장한 적 없으면 기기 다크모드 설정을 따름). 밤에는 Esri Dark Gray Canvas 타일로 바뀝니다.
- 오른쪽 아래 `전체` 는 팀 구역(경남·부산)과 지금 보이는 핀까지 담아 맞추고, `울산` 은 울산 4개 구만 보여줍니다.
- 오른쪽 아래 **`◎` 내 위치** 단추를 누르면 폰의 현재 위치를 받아 **선명한 파란 점(흰 테두리·은은한 정확도 원·펄스)** 으로 찍고 그 자리로 지도를 옮깁니다. 이미 찍혀 있으면 누를 때마다 그 자리로 다시 이동합니다.
  위치 권한을 한 번 허용해 두면 다음부터는 지도를 열 때 조용히 따라갑니다(이미 '허용'된 권한일 때만 — 열자마자 권한 팝업을 띄우지 않습니다). 거부·차단 상태면 누를 때 안내 문구가 뜨고, 끄기는 오른쪽 위 `⚙` → `내 위치 끄기` 입니다.
  내 위치가 켜져 있으면 고객 정보 카드에 **직선거리**(예: `직선 약 3.2km`)가 함께 나옵니다. 울산 밖(양산 집·부산 사무실·이동 중 경남)에 있어도 그 자리로 그대로 이동합니다(경위도를 지도 좌표로 옮기는 식이 전국 공통이고, 타일도 지금 보이는 범위에 맞춰 깔립니다).
- 동선은 시트 `구간` 탭(네이버 길찾기로 받은 점들)을 지나는 부드러운 곡선(Catmull-Rom)으로 그리고, 지도 위에서도 읽히게 바탕색 테두리를 깔아 둡니다. 값을 아직 못 받은 구간은 점선(어림)입니다.
- 경로 추천을 켜면 집(양산)·사무실(부산 강서)까지 포함해 그날 동선 전체가 화면에 들어오게 맞춥니다.

## 고객 정보 카드 (열기 · 닫기)

- 지도의 **점(원)** 을 누르면 **아래 시트 맨 위에 그 고객의 정보 카드**가 뜨고(이름·예약일시·주소·모델·증상·메모·연락처·`📞 전화 걸기`·`길찾기`·접수번호 복사),
  위쪽 지도에서는 **그 점이 짙은 슬레이트 캡슐 이름표(요일 색 1.5px 테두리·작은 요일 점·흰 글자)로 강조**되고, 다른 점에 가리지 않게 가장 위에 그려집니다 — 지도와 정보를 동시에 봅니다. 점이 시트에 가리지 않게 지도를 위로 밀어 올리고, 시트는 중간 높이로 맞춥니다.
- 목록(또는 시트를 접어 둔 상태의 점)에서 한 건을 누르면 시트가 정보 카드로 바뀌며 지도가 그 위치로 확대됩니다(전화는 걸리지 않습니다).
- 닫는 방법: 카드의 **`✕ 목록으로`** · 지도 빈 곳 누르기 · `Esc` 키 · 같은 점을 다시 누르기. 닫으면 시트는 목록으로 돌아갑니다.
  (카드를 연 뒤 지도를 직접 끌거나 확대·축소했다면 닫을 때 화면을 되돌리지 않고 그대로 둡니다.)
- 긴 메모는 세 줄까지만 보이고 `더 보기`로 펼칩니다.

## 이름표와 전화 (전화는 카드 안에서)

- 지도에는 **점만** 깔립니다(요일별 색). 이름표는 지도를 충분히 확대(타일 기준 14단계 이상)하거나 그 점을 고르면 나타납니다 — 기본 화면에서 이름표가 겹쳐 잘못 눌리는 일을 없앴습니다.
- 점이나 이름표를 눌러도 전화가 걸리지 않고, 지도 아래 정보 카드가 열립니다.
- 전화는 상세 카드 안의 **전화번호(`tel:` 링크)** 나 **`📞 전화 걸기`** 버튼을 눌렀을 때만 걸립니다(목록 카드에는 전화 링크가 없습니다).
- 거는 번호는 시트 `방문일정`·`구별 종합현황`의 `전화번호` 칸이고, 이 칸에는 모니터링이 **`증상접수 연락처`를 1순위**로,
  그것이 비어 있을 때만 `01 고객기본정보`의 연락처(대표번호)를 적습니다. `처리실적`의 완료 건은 그 표의 `연락처`를 씁니다.
- 번호가 비었거나 `-`·전산 더미값처럼 쓸 수 없으면 상세 카드에 전화 링크가 없습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 — Esri 회색 타일 위 경남·부산 경계 + 울산 4개 구 강조, 방문 점(요일별 색·미예약 흰 점·완료 회색), 확대·선택 시에만 이름표(선택 핀은 늘 같은 27px 높이의 슬레이트 캡슐), 동선·순서 번호, 상단 두 줄 필터(날짜·구), `⚙` 메뉴(완료 포함·경로 추천·밤/낮·새로고침·잠금), 손가락으로 높이를 조절하는 아래 시트(접힘·중간·크게 3단 스냅, 목록·경로·고객 정보 카드), 카드의 `✕ 목록으로`·전화 `tel:`·길찾기·접수번호 복사, PIN 잠금 |
| `manifest.json` | 앱 이름·아이콘·standalone(전체 화면) 설정 |
| `sw.js` | 화면·아이콘만 캐시(시트 자료·지도 타일은 캐시하지 않음) |
| `icon-*.png` | 앱 아이콘 |

이 저장소에는 고객 정보가 없습니다. 화면 코드와 행정동 중심 좌표만 있습니다.
화면 맞춤에 쓰는 행정동 좌표는 통계청 2013 시군구 경계(공개)를 지도 좌표로 옮긴 것이고, 배경 지도는 Esri Light/Dark Gray Canvas(© Esri, HERE, Garmin, © OpenStreetMap contributors)입니다.

## 자료 연결

`index.html` 의 `API` 상수가 가리키는 Apps Script 웹앱에 `?action=data&pin=…` 로 요청합니다.
PIN이 맞지 않으면 `{ok:false, unauthorized:true}` 가 오고 화면은 PIN 입력으로 돌아갑니다.
경로 추천 설정·순서 저장은 같은 주소로 POST(`{"action":"saveRoute","pin":…,"state":…}`)합니다.
