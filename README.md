# 울산 AS 지도 (PWA)

울산 AS 방문 일정·동선 지도를 폰 홈 화면에서 주소창·안내 배너 없이 여는 웹앱입니다.
정적 파일(GitHub Pages)은 화면만 담고 있고, 자료는 구글 시트에서 PIN 잠금 API로 받아옵니다.

- 주소: https://yuseonghun31-hub.github.io/ulsan-as-map/
- 첫 실행 때 PIN을 입력하면 그 기기(브라우저)에만 저장되어 다음부터는 바로 열립니다.
- 헤더 오른쪽 `잠금` 을 누르면 저장된 PIN이 지워지고 다시 PIN을 묻습니다.
- 폰 세로 화면에서 지도와 아래 목록 사이 손잡이를 위아래로 끌면 지도·목록 높이 비율이 바뀝니다(지도 18~78%, 화면이 낮으면 지도 120px·목록 96px은 남깁니다).
  두 번 누르면 기본(지도 55%)으로, 손잡이 오른쪽 `목록 크게`로 목록을 넓게 볼 수 있고, 정한 비율은 그 기기에 저장됩니다.

## 지도

- 바탕에는 공개 지도 타일(Esri Light/Dark Gray Canvas)을 지금 보이는 범위만큼 깝니다. 열쇠가 필요 없고, 울산 밖(경남·부산 어디든)도 도로·하천이 보입니다.
- 그 위에 경남 22개 시군구와 부산 16개 구, 울산 울주군 경계를 옅게 깔고, 담당 구역인 **울산 남구·중구·북구·동구**만 채도 높은 색과 경계로 도드라지게 그립니다.
- 오른쪽 아래 `전체` 는 팀 구역(경남·부산) 전체, `울산` 은 울산 4개 구만 보여줍니다. 구 칩(남구·중구·북구·동구)은 그 구만 확대합니다.
- 동선은 네이버 길찾기가 준 점들을 지나는 부드러운 곡선으로 그리고, 지도 위에서도 읽히게 바탕색 테두리를 깔아 둡니다. 네이버 값을 아직 못 받은 구간은 점선(어림)입니다.
- 경로 추천을 켜면 집(양산)·사무실(부산 강서)까지 포함해 그날 동선 전체가 화면에 들어오게 맞춥니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 — 배경 타일·경남/울산 경계·구/동 필터·경로 추천·드래그 정렬·지도/목록 높이 조절 손잡이·네이버 지도 열기·접수번호 복사, PIN 잠금 |
| `manifest.json` | 앱 이름·아이콘·standalone(전체 화면) 설정 |
| `sw.js` | 화면·아이콘·배경 타일만 캐시(시트 자료는 캐시하지 않음) |
| `icon-*.png` | 앱 아이콘 |

이 저장소에는 고객 정보가 없습니다. 지도 경계 좌표와 화면 코드만 있습니다.
경계 좌표는 통계청 2013 시군구 경계(공개)를 지도 좌표로 옮긴 것이고, 배경 지도는 Esri 기본 지도(© Esri, HERE, Garmin, © OpenStreetMap contributors)입니다.

## 자료 연결

`index.html` 의 `API` 상수가 가리키는 Apps Script 웹앱에 `?action=data&pin=…` 로 요청합니다.
PIN이 맞지 않으면 `{ok:false, unauthorized:true}` 가 오고 화면은 PIN 입력으로 돌아갑니다.
경로 추천 설정·순서 저장은 같은 주소로 POST(`{"action":"saveRoute","pin":…,"state":…}`)합니다.
